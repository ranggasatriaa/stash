17 Visual legend & tokensWhat to copy when you reuse this theme.

Border 2px on all controls · --st-border

Radius 12px controls · 20px cards · --st-radius / --st-radius-card

Hard shadow 2 · 4 · 6px offset, 0 blur, ink

Spacing 4 · 8 · 12 · 16 · 24 · 32 · 48 · --st-space-1…7

Touch target 44 × 44px minimum · --st-touch

Reuse in another project

:root { --st-orange: #ff5f1f; --st-orange-text: #b53c0c; }

Everything is namespaced st-; base element styles only apply inside .st-body. See docs/MASTER_CSS.md for the full class and token reference.
